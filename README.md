# Cafien ☕

**Cafien** merupakan platform website coffee shop yang menggabungkan sistem pemesanan dan informasi coffee shop dengan teknologi Artificial Intelligence (AI), khususnya Computer Vision.

## Fitur Utama

- Sistem autentikasi pengguna (Login dan Register).
- Informasi dan katalog menu coffee shop.
- Sistem pemesanan kopi.
- Integrasi Artificial Intelligence menggunakan Computer Vision.
- Dashboard pengelolaan coffee shop.

## Teknologi

- **Backend:** Laravel
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **AI / Computer Vision:** YOLO

## Instalasi

Clone repository:

```bash
git clone https://github.com/frizeltech-commits/Cafien.git
```

Masuk ke direktori:

```bash
cd Cafien
```

Install dependency Laravel:

```bash
composer install
```

Salin konfigurasi environment:

```bash
copy .env.example .env
```

Generate application key:

```bash
php artisan key:generate
```

Jalankan aplikasi:

```bash
php artisan serve
```
